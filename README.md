# roadmap

The public roadmap for the [two-go](https://github.com/two-go-testing/two-go)
testing ecosystem.

two-go is a zero dependency, fluent service and API testing library for Node.
This repository tracks what is planned, what is in progress, and what has shipped
across the core library and the tools around it.

## Where to look

- **[ROADMAP.md](ROADMAP.md)** is the full list, grouped by release milestone and
  by area, with a status for every item.

## The ecosystem

The roadmap spans these repositories:

- **[two-go](https://github.com/two-go-testing/two-go)** is the core library.
- **[two-go-examples](https://github.com/two-go-testing/two-go-examples)** holds
  runnable end to end examples.
- **[two-go-docs](https://github.com/two-go-testing/two-go-docs)** is the
  documentation site.
- **[create-two-go](https://github.com/two-go-testing/create-two-go)** scaffolds
  a new test project.
- **[two-go-action](https://github.com/two-go-testing/two-go-action)** runs
  two-go tests in CI.
- **[two-go-vscode](https://github.com/two-go-testing/two-go-vscode)** is the VS
  Code extension.
- **[two-go-claude](https://github.com/two-go-testing/two-go-claude)** is the
  Claude Code skill and subagents.

## How to influence it

Open an issue. Describe the testing problem you hit, not only the feature you
want. Point at the milestone it fits if you know it. Feedback and real usage
decide the order, not the current numbering.
